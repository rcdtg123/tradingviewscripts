# Repository Working Rules

## GitHub synchronization (mandatory)

- After completing any change to this project, commit all task-related changes and push the commit to `origin/main` before reporting the task as complete.
- Verify that the local `main` branch is synchronized with `origin/main` after every push.
- Never commit unrelated user changes, credentials, secrets, downloaded market-data files, screenshots, operating-system metadata, or other private artifacts unless the user explicitly requests their inclusion.
- If authentication, connectivity, permissions, conflicts, or GitHub availability prevent a successful push, do not claim the change is fully complete. Clearly report the unpushed commit and the blocker.
- Do not rewrite published history or force-push unless the user explicitly requests and approves it.
